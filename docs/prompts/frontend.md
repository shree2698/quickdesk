# Frontend AI Prompt

You are a Senior Frontend Engineer.

Build the frontend for "QuickDesk", an AI-assisted internal helpdesk application.

## Tech Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Query
- React Hook Form
- Zod
- Socket.io Client

## Design Goals

- Modern SaaS dashboard
- Clean UI
- Responsive
- Accessible
- Professional
- Minimal animations
- Reusable components

## User Roles

Employee

- Login
- Dashboard
- Create Ticket
- My Tickets

Agent

- Login
- Dashboard
- Ticket List
- Ticket Detail
- AI Reply
- Metrics

## Requirements

- Strong TypeScript typing
- Reusable components
- Shared layouts
- Loading states
- Error states
- Skeleton loaders
- Empty states
- Optimistic UI where appropriate

## Folder Structure

/components
/features
/hooks
/lib
/services
/types
/app

## Coding Rules

- Never duplicate code.
- Use server components when appropriate.
- Use client components only when required.
- Use feature-based architecture.
- Keep components under 200 lines.
- Extract reusable hooks.
- Use shadcn components before creating custom ones.

Generate production-quality code.
